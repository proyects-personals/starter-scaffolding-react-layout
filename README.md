## Tecnologías Principales

- React 18 (Componentes funcionales y Hooks)
- TypeScript (Tipado estático estricto)
- Context API (Gestión de estado global)
- Tailwind CSS + OKLCH (Sistema de diseño adaptable)
- ESLint (Configuración estricta para calidad de código)

---

## Sistema de Temas

El proyecto incorpora una utilidad propietaria denominada `ThemeUtil`, diseñada para:

- Persistencia automática mediante `localStorage`
- Detección de preferencias del sistema operativo
- Resolución dinámica de múltiples temas (Light, Dark y Emerald)
- Integración con sistemas de internacionalización (i18n)
